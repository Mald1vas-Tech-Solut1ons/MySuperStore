# Spec — Vitrine do Ateliê (home)

## CONTRATO (vale para todos os componentes)
- Stack: Next.js 15 App Router, React 19, TypeScript strict, Tailwind 3, framer-motion 11, lucide-react. Todo arquivo começa com `"use client";`. Links internos com `next/link`. Nenhuma lib nova.
- Pasta: `src/components/storefront/`. Exportação nomeada (`export function Nome`).
- Cores Tailwind: `atelie-cream #F4EDE3`, `atelie-sand #E8DCCA`, `atelie-wall #EFE6D8`, `atelie-clay #A65A3A`, `atelie-terracotta #C47A55`, `atelie-olive #5B6146`, `atelie-espresso #2A211B`, `atelie-ink #1F1A17`. Fontes: `font-serif` (Fraunces, títulos; ênfase com `<em>` itálico) e `font-atelie` (DM Sans, corpo). Utilitário `scrollbar-hide` existe.
- Imports existentes (não reescrever):
  - `import { brand, whatsappLink } from "@/config/brand";` → `brand = { name, fullName, tagline, location, shipping, whatsapp, instagram, images: { hero, heroAlt, lookbook: {src,alt}[3], detail } }`; `whatsappLink(text)` retorna `""` sem número.
  - `import { type StoreProduct, type PublicStore, brl, priceOf, compareAtOf, installmentsLabel, youtubeId } from "@/lib/storefront";`
    `StoreProduct = { id, name, slug, base_price: string, promotional_price: string|null, min_price: string, seller_name, seller_slug, category_name: string|null, category_slug: string|null, primary_image: string|null }`
    `PublicStore = { id, store_name, slug, description, logo_url: string|null, banner_url: string|null, product_count: number, avg_rating, video_url: string|null, presentation_video_url: string|null, physical_address, featured_rank }`
    `brl(n)`, `priceOf(p): number`, `compareAtOf(p): number|null`, `installmentsLabel(n): string` (pode ser ""), `youtubeId(url): string|null`.
  - `import { useCartStore } from "@/store/cartStore";` → `{ itemCount }`.
  - `import { useAuthStore } from "@/store/authStore";` → `{ user, isAuthenticated, logout }`, `user?.first_name`, `user?.is_seller`, `user?.role` ("customer"|"seller"|"admin").
- Design: elegante, artesanal, moderno. PROIBIDO: neon, gradiente chamativo, countdown, "oferta relâmpago", "estoque crítico", CAIXA ALTA gritante, dados inventados (notas, nº de vendas, depoimentos). Respiro, `rounded-2xl/3xl`, sombras suaves. Microinterações framer-motion (`whileInView`, `viewport={{ once: true }}`) desligadas com `useReducedMotion()`.
- Acessibilidade: `aria-label` em botões de ícone; `focus-visible:ring-2 focus-visible:ring-atelie-clay`; contraste AA; `alt` real; `<img loading="lazy">` (exceto hero).
- Mobile-first: sem overflow horizontal em 375px; container `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`.
- Textos em português do Brasil, acolhedores e diretos.
- SAÍDA: só o código do arquivo, sem cercas markdown e sem explicação.

## C1 WallBackdrop
`WallBackdrop({ className?, children, tone?: "light"|"warm" })` — "parede descolada" de cal (limewash). Container `relative overflow-hidden`; base `bg-atelie-wall` (light) ou `bg-atelie-sand` (warm). Camadas absolutas `pointer-events-none`: (a) textura de ruído SVG `feTurbulence` em data-URI (baseFrequency ~0.8, numOctaves 3, opacity ~0.18, `mix-blend-multiply`); (b) 2–3 manchas de luz radiais (sol pela janela) derivando devagar em loop 18–25s (framer-motion), paradas com reduced motion; (c) sombra sutil de arco/janela (SVG, opacity 0.06) num canto. Filhos em `relative z-10`.

## C2 SiteHeader
`SiteHeader({ transparentOnTop?: boolean })` — `sticky top-0 z-50`. Barra de anúncio `bg-atelie-espresso text-atelie-cream text-[12px] h-8`: esquerda `${brand.shipping} · Pix com aprovação na hora`; direita `brand.location` (oculta no mobile). Linha `h-16` em grid de 3 colunas: esquerda botão Menu (ícone + "Menu" em sm+); centro wordmark `brand.name` (`font-serif text-xl sm:text-2xl`) e abaixo "macramê" (`text-[10px] uppercase tracking-[0.35em]`); direita: Buscar (abre overlay), conta (`/dashboard/account` se logado, senão `/login`), favoritos `/wishlist` (`hidden sm:flex`), sacola `/cart` com badge `itemCount` (`bg-atelie-clay`) se > 0. Se `transparentOnTop` e `scrollY < 40`: transparente, texto branco, leve `from-black/30`; senão `bg-atelie-cream/90 backdrop-blur-md border-b border-black/5 text-atelie-ink`, com transição.
Overlay MENU em tela cheia (`bg-atelie-cream`, entra com framer-motion; fecha com Esc, X ou clique num link; trava o scroll do body). Links grandes `font-serif text-4xl sm:text-6xl` (hover: itálico + ArrowUpRight clay): Início `/`, Bolsas `/?category=bolsas`, Chapéus `/?category=chapeus`, Calçados `/?category=calcados`, Casa `/?category=casa`, Sob medida (`whatsappLink("Olá! Quero encomendar uma peça sob medida.")` ou `/#encomendas`). Coluna secundária: Minha conta, Pedidos `/dashboard/orders`, Favoritos; "Painel da loja" `/seller/dashboard` se `is_seller`; "Administração" `/admin` se admin; "Venda seu artesanato" `/seller/onboarding` se não for lojista; botão Sair se logado. Rodapé do overlay: location e shipping.
Overlay BUSCA: painel no topo com input grande `font-serif` ("Busque bolsas, chapéus, peças…"); submit → `router.push("/?search="+encodeURIComponent(q))`; sugestões: "bolsa caracol", "boho", "chapéu", "sob medida"; fecha com Esc/clique fora.

## C3 SiteFooter
`SiteFooter()` — `bg-atelie-espresso text-atelie-cream/80`. Grid de 4 colunas (1 no mobile): marca (`brand.name` serif 2xl, tagline, location, shipping); Comprar (Bolsas, Chapéus, Calçados, Casa); Ajuda (Trocas e devoluções `/terms`, Privacidade `/privacy`, Termos `/terms`); Contato (WhatsApp via `whatsappLink("Olá!")` se houver, Instagram `https://instagram.com/{brand.instagram}` se houver; senão "Atendimento pelo WhatsApp em breve"). Linha final `border-t border-white/10`: `© {ano} {brand.fullName}` e link discreto "Plataforma MySuperStore" → `/white-label`.

## C4 HomeHero
`HomeHero({ products }: { products: StoreProduct[] })` — full-bleed `min-h-[88svh] relative overflow-hidden bg-atelie-espresso`. Fundo `brand.images.hero` (alt `brand.images.heroAlt`), `object-cover object-[50%_25%] lg:object-[50%_15%]`; parallax com `useScroll` + `useTransform` (y 0→80px, scale 1.05→1.12), desligado com reduced motion. Overlay `bg-gradient-to-t from-black/75 via-black/25 to-black/10`. Conteúdo alinhado embaixo (`pt-32 pb-12 sm:pb-16`): eyebrow com traço "Ateliê · {brand.location}"; h1 `font-serif text-white leading-[0.95] text-5xl sm:text-7xl lg:text-8xl`: "Feito à mão,<br/><em className='text-atelie-terracotta'>nó a nó.</em>"; parágrafo `Bolsas e peças em macramê criadas uma a uma no ateliê. ${brand.shipping}.`. CTAs: primário `#colecao` "Ver coleção" (`bg-atelie-cream text-atelie-ink rounded-full h-14 pl-6 pr-2`, círculo `h-10 w-10 bg-atelie-clay` com ArrowRight que desliza no hover); secundário "Encomendar sob medida" (`ring-1 ring-white/60 text-white rounded-full h-14 px-6`) → WhatsApp (`target=_blank`) ou `#encomendas`. Em `lg`, à direita embaixo, até 3 chips de vidro com `products.slice(0,3)` (`bg-white/10 backdrop-blur-md ring-1 ring-white/20 rounded-2xl`, thumb 56px, nome, `brl(priceOf(p))`) → `/?product={slug}`. Entrada em cascata (stagger 0.12). Indicador de rolagem discreto.

## C5 AtelierVideo
`AtelierVideo({ videoUrl, fileUrl }: { videoUrl?: string|null; fileUrl?: string|null })` — seção `bg-atelie-espresso text-atelie-cream py-20 sm:py-28`, grid `lg:grid-cols-12 gap-10 items-center`. Texto (`lg:col-span-4`): eyebrow "No ateliê"; h2 serif "Do fio <em className='text-atelie-terracotta'>à peça</em>."; parágrafo "Cada bolsa leva horas de nós feitos à mão, com fio de algodão e acabamento caprichado. Assista ao processo e escolha a sua."; Link `#colecao` "Ver peças". Vídeo (`lg:col-span-8`): `aspect-video rounded-[28px] overflow-hidden bg-black shadow-2xl relative`. Se `youtubeId(videoUrl)`: thumbnail `https://i.ytimg.com/vi/{id}/hqdefault.jpg` + botão Play central (`h-16 w-16 bg-white/90 rounded-full`) + legenda "Do fio à bolsa: o processo no ateliê"; clique troca por iframe `https://www.youtube-nocookie.com/embed/{id}?autoplay=1&rel=0&modestbranding=1` (`allow="autoplay; encrypted-media; picture-in-picture"`, `allowFullScreen`, title). Senão se `fileUrl`: `<video controls preload="metadata" playsInline>`. Senão: placeholder com `brand.images.detail` e faixa "Em breve: vídeos do processo no ateliê". Abaixo: 3 colunas `border-t border-atelie-cream/20 pt-3 text-xs text-atelie-cream/60`: "01 · Escolha do fio", "02 · Nós e trama", "03 · Acabamento".

## C6 ProductCard
`ProductCard({ product, onOpen, index = 0 })` — card inteiro é `<button type="button">` com `aria-label={"Ver "+name}` chamando `onOpen(product.slug)`. Imagem `relative aspect-[4/5] overflow-hidden rounded-2xl bg-atelie-sand`, zoom 1→1.04 no hover (700ms); sem imagem → inicial em `font-serif text-5xl text-atelie-clay/40`. Se `compareAtOf` → selo "-{pct}%" (`bg-atelie-cream/95 text-atelie-clay text-[11px] rounded-full`). Span "Ver peça" que surge no hover (desktop) na base da imagem. Abaixo: `category_name` (`text-[11px] uppercase tracking-[0.18em] text-atelie-ink/50`), nome (`text-[15px]`), preço `brl(priceOf)` semibold + preço "de" riscado, `installmentsLabel` (`text-xs text-atelie-ink/55`) se houver. `motion.div` com entrada whileInView, delay `min(index,8)*0.05`.

## C7 ProductGrid
`ProductGrid({ products, loading, onOpen, title = "A coleção", subtitle?, empty? })` — `<section id="colecao" className="scroll-mt-28 ... py-16 sm:py-24">`. Cabeçalho h2 serif 4xl/5xl, subtitle opcional, contagem "{n} peças" à direita. Grade `grid-cols-2 lg:grid-cols-4 gap-x-4 sm:gap-x-6 gap-y-10` de `ProductCard` (import de `./ProductCard`). Loading: 8 esqueletos `animate-pulse bg-atelie-sand/70`. Vazio: `empty` ou card `rounded-3xl bg-white/50 ring-1 ring-black/5 p-10 text-center` com "Novas peças chegando" (serif 3xl) e "Estamos fotografando as próximas criações. Volte em breve.".

## C8 CategoryRail
`CategoryRail({ categories, active, onSelect })` (`categories: {slug,name}[]`, `active: string|null`, `onSelect(slug|null)`). Barra `sticky top-[96px] z-30 bg-atelie-cream/85 backdrop-blur-md border-b border-black/5`; dentro `flex gap-2 overflow-x-auto scrollbar-hide snap-x py-3`. Chip "Tudo" + um por categoria; `h-10 px-5 rounded-full text-sm whitespace-nowrap snap-start`; ativo `bg-atelie-ink text-atelie-cream` com `aria-pressed`; inativo `bg-white/60 ring-1 ring-black/10 hover:bg-white`. Nada se `categories` vazio.

## C9 Marquee + TrustBar (mesmo arquivo: HomeBits.tsx)
`Marquee({ items })`: faixa `border-y border-black/10 py-4 overflow-hidden`; texto `font-serif italic text-xl sm:text-2xl`, separador "✺" clay; lista duplicada (`aria-hidden` na cópia) em `flex w-max`, keyframes `atelie-marquee` (translateX 0 → -50%, 35s linear infinite) num `<style>`; pausa no hover; parada com reduced motion.
`TrustBar()`: grid `grid-cols-2 lg:grid-cols-4 gap-3`; cards `rounded-2xl bg-white/55 ring-1 ring-black/5 p-4` com ícone lucide clay em círculo cream: QrCode "Pix na hora"/"Aprovação imediata"; CreditCard "Cartão de crédito"/"Parcele sem juros"; Truck "Enviamos para todo o Brasil"/"Frete calculado no carrinho"; ShieldCheck "Compra protegida"/"Pagamento seguro e trocas em 7 dias".

## C11 StoresStrip
`StoresStrip({ stores })` — `null` se `stores.length < 2`. Senão: h2 serif "Ateliês parceiros"; grid `sm:grid-cols-2 lg:grid-cols-3 gap-4` de cards Link `/s/{slug}` (banner `h-36`, avatar `h-14 w-14 -mt-7 ring-4 ring-white`, nome serif xl, `description` com `line-clamp-2`, "{product_count} peças" + ArrowRight).
